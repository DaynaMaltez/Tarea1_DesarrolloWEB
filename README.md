## Descripción del proyecto
Este proyecto consiste en el desarrollo de un prototipo de una tienda en línea de maquillaje inspirada en Sephora, elaborado utilizando únicamente HTML nativo. El sitio incluye varias páginas interconectadas que simulan la navegación de una tienda virtual, con secciones de inicio, catálogo de productos, detalle de productos, carrito de compras. pago y contacto.
